description: Connect Claude Code to a Twilio phone number (owner setup required)
---

Use the `twilio-phone` skill and the `twilio` MCP tools. Start with `twilio_status`. If the account is not connected, ask the owner to set `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, and `TWILIO_PHONE_NUMBER` in their shell or write the 0600 credentials file described by `twilio_setup_guide`. Never ask them to paste credentials into chat. Confirm that trial-recipient numbers are verified in the Twilio Console before placing a call.
